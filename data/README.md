# Synthetic dataset

Everything here is fictional and generated by `python -m supplierguard.data_gen` (seed 42).
Regenerating with the same seed reproduces these files byte for byte.

| Path | Used by | Content |
|---|---|---|
| `suppliers.json` | all | 50 fictional suppliers: id, name, industry, country, city |
| `documents/<id>/*.txt` | Document Intelligence agent (RAG) | `contract`, `security_assessment`, `compliance_audit`, `legal_filings`. Contain fake PII (emails, phones, bank details, names) so the scrubber has something real to remove |
| `financials.csv` | Financial and Operational agent | 8 quarters per supplier: revenue, margin, debt to equity, current ratio, credit score |
| `delivery.csv` | Financial and Operational agent | 12 months per supplier: on-time %, defect rate, SLA breaches, quality score |
| `news/<id>.json` | External Signals agent | 8 articles per supplier, mixed positive, neutral and negative |
| `dependency.json` | Strategic Risk agent | Spend share, qualified alternatives, switching time, single-source flag |
| `ground_truth.json` | evaluation only | Latent 1 to 10 score per dimension, risk tier, golden/holdout split |

`ground_truth.json` must never be given to an agent or placed in a prompt. The scores in it
are the parameters the other files were generated from. They are ground truth by
construction, not human expert labels.

Company names are invented. Any resemblance to a real company is coincidental.
